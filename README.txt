CSE1101 — UNIVERSITY OF GUYANA STUDY HUB
=========================================

WHAT IS INCLUDED
- 11 complete lesson pages matching the supplied 11-week syllabus
- 112 practice multiple-choice questions, each with an explanation
- Eight 18-question mock midterm papers, timed at 35 minutes each
- Flashcards covering every topic
- Printable reference / formulas sheet
- Lesson completion tracking and practice score history
- Responsive mobile layout and light/dark appearance

TO OPEN THE SITE
OPTION A: Open standalone.html in your web browser. All CSS and JavaScript
          are included inside this single file. No installation needed.
OPTION B: Open index.html in your web browser, keeping styles.css, data.js,
          and app.js in the same directory.

Both versions work without an internet connection. Progress is stored locally
by your browser and device. Clearing browser site data may clear progress.

TO EDIT THE WEBSITE
Edit index.html (structure), styles.css (appearance), data.js (course content)
and app.js (interactions). The standalone.html copy is prebuilt and does not
update automatically when you edit the separate source files.

IMPORTANT NOTES
The user-provided image lists Weeks 1-11 but does not define the actual
midterm cutoff. This study hub emphasizes Weeks 1-6 as a suggested revision
set. Weeks 7-11 remain fully accessible and can be selected in practice mode.
Confirm exam coverage with your University of Guyana lecturer.

These are original practice questions, not official University of Guyana
exam papers. This independent revision resource is not an official UG site.
